# Terraform

Thư mục dành cho provisioning hạ tầng bên ngoài Kubernetes.

## Planned scope

- Network and firewall rules
- Kubernetes cluster or VM nodes
- Storage classes and persistent disks
- DNS and ingress dependencies
- Backup storage

Hiện tại chưa có Terraform module để tránh khóa repository vào một cloud provider quá sớm.
